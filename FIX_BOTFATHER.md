# СРОЧНО: Настройка BotFather для Mini App

## Проблема найдена!

`initData` пустой → Telegram не передаёт данные авторизации.

**Причина:** Mini App открывается не через официальную точку входа (Menu Button).

---

## Решение: правильно настрой Mini App в BotFather

### Шаг 1: Открой @BotFather

В Telegram найди и открой **@BotFather**

### Шаг 2: Настрой Mini App

Отправь команды:

```
/mybots
```

→ Выбери своего бота (@google_calendar_booking1_bot)

→ Нажми **"Bot Settings"**

→ Выбери **"Menu Button"**

### Шаг 3: Укажи URL Mini App

BotFather спросит URL. Отправь:

```
https://calendar.vpncfo.ru
```

**ВАЖНО:**
- БЕЗ `/#/` в конце
- БЕЗ `/index.html`
- Просто домен

### Шаг 4: Укажи название кнопки (опционально)

BotFather может спросить текст кнопки. Можешь оставить по умолчанию или написать:

```
Открыть приложение
```

---

## Альтернатива: если нет Menu Button

Если в настройках нет "Menu Button", возможно нужно настроить как **Web App**:

### Вариант А: Через команду /newapp

```
/newapp
```

→ Выбери своего бота
→ Укажи название: `Календарь`
→ Укажи URL: `https://calendar.vpncfo.ru`
→ Укажи короткое имя: `calendar` (для short link)

### Вариант Б: Через /setmenubutton (новый способ)

```
/setmenubutton
```

→ Выбери своего бота
→ **Edit Menu Button**
→ Укажи URL: `https://calendar.vpncfo.ru`

---

## После настройки

1. **Перезапусти Telegram** (полностью закрой и открой)
2. Открой бота
3. Теперь должна появиться кнопка внизу (рядом с полем ввода)
4. Нажми кнопку → Mini App откроется **с валидным initData**

---

## Проверка: откуда открываешь?

**ПРАВИЛЬНО:**
- Telegram → бот → кнопка внизу (Menu Button) → открывается Mini App
- `initData` будет заполнен

**НЕПРАВИЛЬНО:**
- Прямая ссылка https://calendar.vpncfo.ru в браузере
- Inline-кнопка в сообщении (не Menu Button)
- `initData` будет пустой → 422 ошибки

---

## Что должно быть в итоге

После правильной настройки:

1. В боте появится **синяя кнопка внизу** (где обычно стикеры)
2. При нажатии открывается Mini App **внутри Telegram**
3. В консоли будет:
   ```
   [API] initData length: 200+ (не 0!)
   ```
4. Все запросы будут возвращать 200 OK (не 422)

---

## Текущая команда BotFather (пробуй по очереди)

1. Сначала попробуй `/setmenubutton` (новый способ)
2. Если нет — `/mybots` → Bot Settings → Menu Button
3. Если нет — `/newapp` (создание Web App)

Пришли скриншот, если BotFather не показывает эти опции.
