## Контекст

Проект **Smart Scheduler** — бот для записи на встречи через Telegram Mini App. Пользователь видит доступные слоты в календаре, выбирает время и создаёт заявку. Админ модерирует заявки и подтверждает → событие автоматически попадает в Google Calendar + Meet.

**Реализовано:**
- ✅ Backend API (FastAPI, SQLite, Google Calendar OAuth)
- ✅ Telegram бот (aiogram 3, модерация, "/admin", "/my")
- ✅ Mini App frontend (React + TypeScript + Vite)
- ✅ Деплой на Dokploy (calendar.vpncfo.ru)
- ✅ Отладка валидации initData (HMAC + Ed25519)
- ✅ Базовая запись работает (недели → дни → слоты → форма → pending → модерация)

**Что сейчас работает:**
- Запуск через Menu Button в Telegram
- Загрузка календаря (недели с доступными днями)
- Выбор дня → загрузка слотов времени
- Создание заявки через форму
- Уведомление админу с кнопками "Подтвердить/Отклонить/Бан"
- Создание события в Google Calendar при подтверждении

## Специфика Mini Apps Telegram

1. **initData:** передаётся автоматически (Telegram SDK), используется для аутентификации API. Не удаляй логику в `api.ts:sendRequest()`.
2. **HashRouter:** используй `/#/path`, не `BrowserRouter` (нужен для fallback).
3. **Telegram SDK:** инициализируется в `index.html` **до** React. Не переноси в компоненты.
4. **Тёмная тема:** учти `window.Telegram.WebApp.colorScheme` ('light' | 'dark') для переключения CSS.
5. **Haptic:** используй `Telegram.WebApp.HapticFeedback` для тактильной отдачи (клики, ошибки).

## Стиль кода (из `.cursor/rules/core.mdc`)

- **Язык:** русский для комментариев, документации, сообщений пользователю
- **Код:** английский для переменных/функций
- **Будь лаконичен:** код сразу, без «водянистых» объяснений
- **Не ломай существующее:** безопасные изменения, проверяй перед коммитом
- **Логи:** важные действия → `logging` (backend) или `console.log` (frontend для отладки)
