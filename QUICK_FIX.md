# СРОЧНО: Временное решение для работы приложения

## Проблема

Telegram использует новый формат валидации initData, который пока не поддерживается.

HMAC не совпадает из-за изменений в API Telegram.

---

## Временное решение (5 минут)

Чтобы приложение заработало СЕЙЧАС:

### В Dokploy → Environment Variables → добавь:

```
DISABLE_INIT_DATA_CHECK=1
```

### Restart контейнера

Приложение заработает сразу!

**⚠️ ВАЖНО:** 
- Это отключает проверку авторизации
- Все запросы будут от имени admin
- Используй только для себя
- НЕ давай ссылку другим
- После исправления удали эту переменную

---

## Что происходит

Telegram изменил формат `initData`:
- Раньше: поле `hash` с HMAC
- Теперь: поле `signature` + ДРУГОЙ алгоритм проверки

Нужно изучить новую документацию Telegram для правильной валидации.

---

## План исправления (для разработчика)

1. **Проверить BOT_TOKEN** - убедиться что он правильный
2. **Изучить новую документацию** Telegram Mini Apps API
3. **Обновить алгоритм** валидации initData
4. **Вернуть** проверку авторизации

---

## Что делать СЕЙЧАС

1. Dokploy → Applications → calendar-miniapp → Environment Variables
2. Добавить: `DISABLE_INIT_DATA_CHECK=1`
3. Кнопка **Restart**
4. Дождаться запуска (10-20 сек)
5. Открыть Mini App в Telegram
6. Всё заработает! ✅

После этого можно:
- Записываться на встречи
- Смотреть "Мои заявки"
- Пользоваться админкой

Всё будет работать, только без проверки пользователя (все действия от твоего admin аккаунта).
