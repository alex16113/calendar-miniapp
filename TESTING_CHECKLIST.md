## Перед началом

1. **Дождитесь деплоя:**
   - Push в main → автодеплой на Dokploy
   - Обычно занимает 2-3 минуты
   - Можно проверить логи в Dokploy панели

2. **Откройте бота:**
   - Найдите @google_calendar_booking1_bot в Telegram
   - Нажмите "Открыть приложение" (синяя кнопка внизу)
   - Если кнопки нет — напишите `/start`

## Типичные проблемы

### Белый экран
- **Причина:** initData отсутствует
- **Решение:** Открыть через Menu Button в боте, не через браузер

### 401 ошибки
- **Причина:** Валидация initData не прошла
- **Решение:** Проверить логи Dokploy, убедиться что BOT_TOKEN корректный

### 422 ошибки
- **Причина:** Неверные параметры API
- **Решение:** Проверить логи backend, посмотреть что именно не прошло валидацию

### Не работает haptic feedback
- **Причина:** Старая версия Telegram или не поддерживается на устройстве
- **Решение:** Обновить Telegram, проверить на другом устройстве

## Сценарии для тестирования

### Сценарий 1: Новая заявка (happy path)
1. Открыть бота через Menu Button
2. Нажать "Записаться"
3. Выбрать длительность (например, 30 мин)
4. Выбрать день (например, завтра)
5. Выбрать время (например, 14:00)
6. Заполнить форму (имя, тема, email)
7. Отправить
8. Проверить успешное создание
9. Перейти в "Мои заявки"
10. Убедиться, что заявка появилась со статусом "Ожидание"

### Сценарий 2: Отмена заявки
1. Открыть "Мои заявки"
2. Найти pending заявку
3. Нажать "Отменить заявку"
4. Подтвердить в confirm
5. Убедиться, что заявка удалилась

### Сценарий 3: Модерация (для админа)
1. Открыть Admin панель
2. Увидеть список pending
3. Нажать "✓ Подтвердить" на первой заявке
4. Убедиться, что заявка удалилась из списка
5. Проверить в Google Calendar, что событие создано

### Сценарий 4: Темная тема
1. Переключить Telegram на темную тему
2. Открыть Mini App
3. Пройти по всем экранам
4. Убедиться, что всё читаемо и контрастно
